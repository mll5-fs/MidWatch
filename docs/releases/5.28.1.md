# MidPulse 5.28.1 — comptes partagés exclus même sans rapport

Défaut reproduit avant correction par neuf tests : dans les matrices multirôles, le contrôle des comptes/identités partagés utilisait uniquement les rôles dont le pool était exploitable. Si l’autre rôle partageant le compte n’avait pas de rapport, de partie sur le patch ou de champion identifiable, le premier rôle pouvait être retenu et former à tort une observation multirôle avec un troisième joueur.

Le contrôle porte désormais sur toutes les identités sélectionnées des cinq rôles, indépendamment de la disponibilité des rapports. Exclusion des deux rôles concernés, sans modifier les données sources, réétiqueter des titulaires ou renouveler la mémoire. Le rapport détaillé reconstruit aussi les cinq paires courantes, y compris sans analyse mémorisée, et ne leur rattache un rapport que si équipe/joueur/compte correspondent. Matrices et rapport détaillé utilisent la même règle. Explication visible dans les pools et l’export. Pas de nouvel appel Riot.

Parcours : Équipes OUAT → Pools draft → Champions observés sur plusieurs rôles. La couverture et les champions affichés peuvent diminuer quand une composition partage un compte ; corriger les comptes ou le choix de composition plutôt que charger le rapport manquant pour contourner l’exclusion. Dix régressions : rapport manquant/en erreur/mauvais rôle/vide/sans champion/incohérent/patch absent, joueur dupliqué, accord renderer-export et rôle sans aucune analyse. Neuf premiers tests en échec avant correction ; dixième ajouté pour l’absence totale d’analyse dans l’export.
