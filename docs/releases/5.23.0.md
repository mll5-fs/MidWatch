# MidPulse 5.23.0 — Parcours de préparation d’équipe

Dans Équipes OUAT, après sélection d’une équipe : nouveau sommaire « PRÉPARATION » avec accès directs à Effectifs et rangs, Suivi Riot, Rangs du groupe, Pools draft, Vue des 5 rôles, Comparateur détaillé et Rapport à copier.

Les effectifs des cinq rôles, leurs choix de composition locale et la moyenne observée sont maintenant placés avant les grands tableaux/rapports. Les mêmes données et limites restent affichées : conversion descriptive des rangs officiels, couverture sur cinq rôles, rangs absents/partiels/périmés exclus, pas de MMR ni confirmation des titulaires LEA. Aucune collecte n’est ajoutée par les liens.

Liens internes natifs, destinations uniques nommées et focalisables, focus clavier visible, marge de défilement pour la barre supérieure, liens repliés sur plusieurs lignes aux petits écrans. Les liens de pools/comparaison ne sont proposés qu’avec une équipe adverse et UWU GANG distincts ; un groupe non publié mène à son explication plutôt qu’à un export inventé. Pas de nouvelle mémoire ou de filtre statistique ; les collectes et filtres existants restent inchangés.

Huit nouvelles régressions exécutent le véritable renderer en VM : ordre des sections/effectifs, correspondance de chaque lien à une destination unique, cinq rôles et dix fiches sur une comparaison, UWU seul/absent, groupe inconnu, recherche sans résultat, changement d’équipe et fiches joueurs, échappement HTML et règles CSS de focus/petits écrans. Le vérificateur du paquet est actualisé pour imposer le nouvel ordre au lieu de l’ancien ordre des rapports.

Version inédite 5.23.0, interface toujours depuis Electron app.getVersion(). Livraison vérifiée par Windows CI et inspection de l’installateur public (empreinte, app.asar, version, fichiers et tests sur code extrait), preuves finales dans la PR. Aucun test interactif Windows/LoL ni appel Riot authentifié. Les tests VM et les contrôles CSS n’établissent pas une validation visuelle ou clavier dans l’application native.

Veille du 18 octobre 2026 : https://developer.riotgames.com/docs/lol, https://developer.riotgames.com/docs/portal, https://dpm.lol/changelog. Le parcours organise les données existantes, sans nouvelle inférence de micro-gameplay ni donnée de joueur inventée. Effectifs LEA renouvelés au build.
