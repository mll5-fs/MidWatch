# MidPulse 5.28.3 — une seule instance, retour à la fenêtre existante

Relancer MidPulse depuis le raccourci utilise désormais le verrou d’instance Electron : seul le propriétaire du verrou démarre le cycle des fenêtres. Une seconde instance quitte sans créer sa fenêtre ni démarrer son rendu/collectes. La première restaure sa fenêtre minimisée, montre une fenêtre masquée et lui donne le focus. Les événements ne transmettent ni comptes, clé, arguments CLI ou tâches à exécuter.

Ce garde réduit les collectes et écritures de configuration concurrentes entre versions qui utilisent ce verrou. Il ne ferme pas rétroactivement une ancienne version sans verrou déjà ouverte, ne remplace pas une vérification d’installation et n’impose pas d’arrêt forcé. Fermer toutes les anciennes fenêtres avant installation ; vérifier la version affichée. Les données OUAT/compositions, cinq rôles et version depuis app.getVersion sont conservés.

Neuf régressions : secondaire sans démarrage, primaire après readiness, fenêtre minimisée/masquée, visible, absente/détruite, getter courant, activate et comportements fermeture Windows/macOS, branchement réel main. Tests Node/VM du cycle Electron, pas essai interactif natif Windows.
