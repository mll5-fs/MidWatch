# MidPulse 5.12.0 — Préparation d'équipe multi-rôles

Dans 5.11.1, changer de rôle effaçait la comparaison précédente. Le rapport de préparation n'incluait que le rôle courant. Cette version prolonge le comparateur existant, sans reconstruire l'application.

## Parcours visible

Équipes OUAT → sélectionner un adversaire → Comparateur SoloQ → charger un rôle. Dans « ANALYSES MÉMORISÉES · 5 RÔLES », les boutons affichent les rapports disponibles sur deux comptes et les tailles d'échantillon. Charger les autres rôles reste un acte explicite, pas une collecte de dix rapports lancée automatiquement.

Revenir sur un rôle déjà chargé restaure ses rapports sans nouvel appel Riot. « Actualiser ce rôle » permet une demande explicite (le cache backend et les pauses Riot restent applicables). Les comparaisons restent mémorisées pendant quinze minutes, au maximum trente paires, uniquement dans la session. Changer d'équipe, de joueur choisi ou de compte utilise une identité distincte. Les réponses tardives sont ignorées après navigation. Fermer l'application efface cette mémoire.

« Copier le rapport d'équipe » inclut désormais tous les rôles mémorisés pour les joueurs/comptes actuellement choisis, avec périodes, dates de collecte, échantillons et limites. Le rôle courant conserve son filtre de patch ; les autres sont exportés sur toutes leurs parties retenues, explicitement étiquetées. Les rôles non chargés restent signalés. Une collecte interrompue, un résultat vide ou une erreur ne devient pas une analyse complète.

La durée de mémoire ne prouve pas que l'historique est récent : les dates d'origine ne sont pas remplacées par l'heure de restauration. Les rapports restent des historiques SoloQ individuels au rôle déclaré, pas des confrontations directes ni un pronostic. Aucun nouveau calcul de MMR ou inférence de micro-gameplay.

## Vérifications

Tests : retour entre les cinq rôles sans nouvel appel, navigation/cancellation, expiration et limite mémoire, changement de compte/composition, collecte partielle/vide, export multi-rôles/patchs, boutons de navigation et absence de données privées. Windows CI puis contrôle indépendant du NSIS/app.asar requis avant livraison vérifiée. Aucun essai interactif Windows/LoL ou appel Riot authentifié.

Sources consultées le 17 octobre 2026 : https://developer.riotgames.com/docs/lol (identification publique Riot ID/PUUID et contraintes) ; https://dpm.lol/changelog (évolutions de l'outil de scouting, contexte seulement). Aucune fonctionnalité DPM supposée disponible dans MidPulse.
