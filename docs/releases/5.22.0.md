# MidPulse 5.22.0 — Export des rangs de tout le groupe

Équipes OUAT → division/groupe ou « Voir le groupe d’UWU GANG » → tableau Rangs moyens du groupe → « Copier les rangs du groupe » ; aperçu dépliable disponible.

Toutes les équipes du groupe LEA sélectionné sont exportées, indépendamment de la recherche de joueurs. Le texte contient la date de génération, saison/date d’effectif, moyennes observées avec couverture sur cinq rôles, cinq rôles par équipe, noms/Riot IDs publics, dernier rang disponible et date de vérification, choix locaux et motifs d’exclusion. UWU GANG sert de repère uniquement s’il appartient au groupe sélectionné ; aucun ajout depuis un autre groupe.

Les équipes complètes suivent le même ordre descriptif que le tableau, ex æquo conservés ; les autres restent par nom sans position attribuée. Pas un classement du tournoi ni du MMR réel. Conversion explicitée : 100 points/division, 400/palier + LP ; Master/Grandmaster/Challenger partagent la base Master + LP. Les rôles absents/ambigus, comptes partagés, rangs partiels ou périmés sont exclus. Les choix locaux ne confirment pas les titulaires officiels.

L’aperçu est reconstruit avec les données courantes et la fraîcheur des rangs est réévaluée au clic, sans collecte Riot supplémentaire. Échec du presse-papiers : aperçu texte conservé pour sélection manuelle et bouton réactivé. Aucun export si le groupe devient indisponible. Champs explicitement projetés, jamais les objets de configuration bruts.

Douze nouvelles régressions : périmètre division/groupe complet, cinq rôles, ordre/ex æquo/incomplets, dates périmées/futures, joueurs manquants/ambigus, composition locale, compte partagé/erreur/partiel, Master+, absence UWU hors groupe, groupe inconnu, projection sans mutation, copie réelle simulée et échecs récupérables.

Nouvelle version 5.22.0, version UI toujours depuis Electron app.getVersion(). Tests Windows puis contrôle du téléchargement public : SHA-256, extraction NSIS/app.asar, fichiers et version, tests sur code extrait. Preuves finales dans la PR. Aucun essai interactif Windows/LoL ni appel Riot authentifié ; tests VM et inspection d’artefact ne les remplacent pas.

Veille consultée le 18 octobre 2026 : https://developer.riotgames.com/docs/lol (rangs officiels, pas de score MMR alternatif), https://developer.riotgames.com/docs/portal (quotas existants conservés), https://dpm.lol/changelog (outils de scouting). Effectifs renouvelés depuis LEA au build ; aucun joueur, Riot ID ou rang inventé.
