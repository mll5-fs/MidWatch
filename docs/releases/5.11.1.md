# MidPulse 5.11.1 — Pause Riot partagée entre les collectes

## Défauts constatés dans le code 5.11.0

Après une réponse LIVE 429, la boucle poursuivait les autres comptes et joueurs du lot. La pause des rangs ne protégeait pas les autres appels publics Riot. Le parseur Retry-After raccourcissait aussi toute durée supérieure à dix minutes. Ces constats proviennent du code et de tests avec transport simulé, pas d'une mesure du service Riot réel.

## Correctif

- Pause conservatrice par clé, partagée dans le processus entre toutes les routes publiques Riot (LIVE, rangs, comptes, matchs et validation de clé). Les autres régions/méthodes utilisant la même clé sont volontairement suspendues aussi ; pas de tentative de contourner une limite par une autre route.
- Une réponse 429 pose une échéance absolue. Aucun nouvel appel HTTP de cette clé ne part avant celle-ci. Pas de retry automatique de la requête refusée et pas d'annulation des appels déjà en vol. Les durées Retry-After valides ne sont plus raccourcies ; en-tête absent/invalide : repli local de 120 secondes.
- Le lot LIVE et les comptes secondaires s'arrêtent immédiatement sur 401, 403 ou 429 ; le nombre de joueurs vérifiés reflète les tentatives réelles. Une erreur reste une donnée indisponible, jamais une preuve de hors-ligne.
- LIVE et rangs partagent la pause côté interface. Un ancien lot de rangs ne peut pas effacer une pause LIVE plus récente. L'indicateur Riot API affiche les secondes restantes et se met à jour lors des rendus périodiques ; ce n'est pas un compteur animé à la seconde.
- Les passes périodiques reprennent quand la pause a expiré. Les délais/quotas peuvent encore ralentir la collecte. Une réponse 401/403 interrompt la collecte automatique jusqu'à validation de la configuration ; elle peut aussi indiquer un problème de droits ou de route, pas forcément une clé expirée.

Parcours : Équipes OUAT → suivi des joueurs ; en cas de limite, consulter l'indicateur Riot API. Les statuts LIVE périmés continuent à devenir « à revérifier » (5.11.0). Aucun rang manquant n'est inventé.

## Vérifications et sources

Tests avec horloge et transport simulés : partage entre instances/routes, échéance et reprise, isolation des clés, absence de retry, fallback, délais > 10 min, interruption multi-comptes/lots, compteurs réels, échéance absolue des rangs, pause UI et course entre collectes. Windows CI et inspection du nouvel installateur restent requis avant livraison vérifiée. Aucun essai interactif Windows/LoL ou appel Riot authentifié.

Consulté le 17 octobre 2026 : documentation officielle Riot https://developer.riotgames.com/docs/portal (réponses 401/403/429, Retry-After et limites) et changelog de l'outil de scouting DPM https://dpm.lol/changelog . La pause partagée est une décision conservatrice de MidPulse ; elle ne prétend pas reproduire la granularité interne des quotas Riot.
