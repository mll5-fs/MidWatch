# MidPulse 5.11.0 — Suivi LIVE des équipes consultées

## Problème observé dans le code 5.10.2

La rotation LIVE portait sur huit joueurs toutes les vingt secondes, sans priorité de consultation ni expiration des observations. Pour 1 419 joueurs, un tour complet représente au minimum 178 passes, soit 59 min 20 s hors latence. Ce calcul décrit le planificateur, pas une mesure réelle des délais Riot.

## Évolution visible

Dans Équipes OUAT, les joueurs de l'équipe sélectionnée et d'UWU GANG sont prioritaires. Chaque ligne de rôle affiche le statut et l'heure de la dernière vérification disponible. La file garde huit joueurs par passe, jusqu'à six prioritaires avec une rotation équitable ; au moins deux places restent pour l'arrière-plan lorsqu'il existe. Les joueurs sans compte relié ne provoquent aucun appel.

Le rang SoloQ n'est pas modifié par cette évolution. LIVE et HORS LIGNE expirent après deux minutes sans observation récente ; ils deviennent inconnus/à revérifier. Une erreur Riot ne confirme pas une déconnexion. Les délais, quotas, clé manquante et collectes incomplètes peuvent empêcher le suivi. L'étiquette LIVE n'est pas une garantie de lancement du spectateur.

La priorité est transmise au prochain passage périodique (20 s nominales), sans requête supplémentaire au clic. La collecte en cours peut retarder le changement de priorité. Une seule collecte backend est active, comme auparavant.

## Vérifications requises

Tests du budget/rotation/priorités, expiration des observations, absence de faux hors-ligne, métadonnées d'identité de la 5.10.2 conservées, IPC et affichage. Vérification Windows CI puis téléchargement, SHA-256 et inspection du NSIS/app.asar avant livraison déclarée vérifiée. Aucun test interactif dans le client LoL réel.

Sources consultées le 17 octobre 2026 : documentation officielle Riot https://developer.riotgames.com/docs/lol et outil de scouting https://dpm.lol/ (suivi d'équipe SoloQ). La durée de validité de deux minutes est une règle d'interface MidPulse, pas une garantie de fraîcheur de Riot.
