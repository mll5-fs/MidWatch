# MidPulse 5.18.0 — Récupération explicite après échec

Dans Équipes OUAT, comparateur d'un rôle face à UWU GANG : après un échec ou une actualisation partielle, le bouton « Revenir au rapport précédent (daté) » permet de récupérer les deux rapports précédents ensemble. Aucun appel Riot supplémentaire, aucun mélange ancien/nouveau et aucune prolongation de leur durée de mémoire de quinze minutes.

Le nouvel échec reste affiché tant que l'utilisateur ne choisit pas la restauration. Un avertissement persiste dans le comparateur, la synthèse des cinq rôles, les pools draft et l'export. Une nouvelle collecte réussie supprime le secours ; les changements de contexte et l'expiration le rendent indisponible. Un lot explicitement relancé retente aussi les paires restaurées. Cette récupération concerne l'actualisation manuelle d'un rôle.

## Vérifications

- Quatorze nouvelles régressions : cinq rôles, restauration atomique, premier échec sans historique, erreurs d'authentification/quota, résultats partiels, expiration et recul d'horloge, changements de contexte, échecs répétés, succès avec zéro partie, mémoire et relance par lot.
- Le test du parcours lie le vrai gestionnaire de clic aux rapports, à la synthèse, aux pools et à l'export. Ce test simulé n'est pas un essai Windows interactif.
- Le workflow Windows vérifie les sources embarquées et extrait le véritable installateur avant publication. La preuve indépendante de téléchargement et d'inspection est consignée dans la PR après publication.
- Version affichée toujours issue d'Electron app.getVersion(). Aucun rang, joueur ou Riot ID inventé.
