# MidPulse 5.14.0 — charger les cinq rôles OUAT

Date : 17 octobre 2026. Base : 4ef79ecab569c332d12d726e00ac0e9fb57fc400 (5.13.0).

## Parcours visible

Équipes OUAT → adversaire → Analyses mémorisées · 5 rôles → **Charger les 5 rôles**. Le lot utilise les compositions locales et comptes du comparateur existant face à UWU GANG. Chaque rôle indique sa progression, ses blocages ou la réutilisation de sa mémoire. Le comparateur individuel et l’export d’équipe récupèrent les résultats terminés.

## Fiabilité

- Deux rapports par rôle au maximum, demandés successivement ; pas de boucle automatique de reprise.
- Réutilisation des deux rapports complets mémorisés moins de quinze minutes, sans changer leurs dates d’observation ni leur expiration. Les rapports partiels/erreurs sont retentés seulement après une nouvelle action explicite.
- Rôles manquants, comptes absents, doublons de compte entre adversaires et rôles ambigus : bloqués avec raison, jamais inventés.
- Erreur, arrêt d’authentification ou quota Riot : arrêt des rôles suivants, conservation des données mesurées avec leurs limites.
- Annulation explicite, navigation principale, changement d’équipe, compte, composition ou disponibilité de clé : aucun résultat en attente ajouté au nouveau contexte. Une requête IPC déjà partie peut encore finir côté backend.
- Chargement individuel et chargement des cinq rôles ne se déclenchent pas simultanément depuis cette interface.

## Vérification et livraison

Tests automatisés locaux : 256 réussis, dont 14 nouveaux couvrant séquence, réutilisation, expiration, données manquantes, erreurs, auth/quota, annulation, changement de contexte, doublons, interface et export. Vérification de syntaxe prévue dans les tests Windows. Le contrôleur du lot et ses commandes UI sont obligatoires dans le contrôle du paquet Electron, y compris après extraction NSIS dans le workflow.

La version doit provenir de package.json via Electron app.getVersion(). Nouvelle release v5.14.0 uniquement ; aucun installateur existant remplacé. La preuve finale commit → build Windows → asset, son empreinte et l’inspection indépendante seront consignées dans la PR après publication.

Limites : tests simulés et inspection d’artefact ; aucun appel Riot authentifié ni test interactif Windows/LoL. Les statistiques restent des historiques SoloQ individuels au rôle déclaré, sans confrontation directe, pronostic, causalité de patch ou analyse du micro-gameplay. Pas de nouvelle affirmation sur les effectifs/groupes : snapshot LEA actualisé par le build.
