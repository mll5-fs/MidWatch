# 5.6.0 — Compositions locales OUAT

Dans Équipes OUAT, chaque rôle propose un sélecteur « Composition locale ».
Il permet de choisir parmi les joueurs réellement déclarés par LEA, sans
modifier l'effectif ni prétendre confirmer les titulaires officiels.
Le choix est conservé dans la configuration Electron et s'applique à la moyenne
de l'équipe, au tableau du groupe et à la comparaison UWU GANG.
Revenir au choix automatique retire la sélection : un rôle avec plusieurs
joueurs redevient exclu de la moyenne. Un joueur parti ou ayant changé de rôle
est signalé comme choix absent, sans substitution silencieuse.

Les rangs doivent toujours être complets, distincts et vérifiés depuis moins
de quinze minutes. Une composition ne crée aucun rang ni compte manquant.
La moyenne reste un résumé descriptif des rangs officiels, pas le MMR réel.

Validation locale : syntaxe, 152 tests automatisés, dont calculs avec remplaçant,
choix absent, doublons, péremption, validation IPC, conservation dans les données
de configuration et gestion d'un échec d'enregistrement dans le renderer.
Le workflow Windows exécute les tests puis inspecte le contenu de l'installateur.
La publication et le contrôle indépendant de l'asset sont à confirmer dans le
compte rendu de livraison : ce document n'en constitue pas la preuve.
Aucun test interactif Windows ou client LoL effectué localement.

Sources consultées le 16 octobre 2026 : documentation Riot
https://developer.riotgames.com/docs/lol (Riot ID/PUUID, limites d'usage et
interdiction des systèmes alternatifs de classement) ; https://dpm.lol
(Team SoloQ et outils de comparaison). Effectifs fournis par
https://api.leamateur.pro ; aucun titulaire officiel déduit des rôles déclarés.
