# MidPulse 5.19.1 — Pauses Spectate cohérentes

Dans Équipes OUAT → fiche joueur → Spectate, les boutons affichent désormais « Pause · N s » après une demande acceptée, un lancement dont la réponse est incertaine ou un refus local HTTP 429. Le titre distingue acceptation, incertitude et client occupé. L'acceptation ne confirme jamais le lancement du jeu.

Le garde-fou principal expose uniquement l'échéance et le motif de sa pause par une lecture IPC locale, sans clé, compte, requête Riot ou POST au client League. L'interface la lit après une erreur : la sérialisation des erreurs Electron ne masque plus cette pause.

Les refus 429 du client local conservent le délai Retry-After numérique ou HTTP-date lorsqu'il est exploitable. Pause minimale locale de quinze secondes ; une durée valide plus longue est respectée. Les dates passées, valeurs invalides ou arithmétiquement dangereuses n'inventent pas de délai serveur. Les réponses POST incertaines gardent leur pause de quinze secondes. Les erreurs avant lancement sans pause peuvent être corrigées et retentées.

Le compte à rebours est local : aucune relance automatique et aucun appel réseau à son expiration. Les profils ouverts pendant la pause respectent le même état. Si la lecture IPC échoue elle-même, l'erreur initiale reste affichée et le garde-fou principal reste responsable de bloquer les doublons.

## Vérifications et limites

Douze nouvelles régressions couvrent HTTP → classification → garde-fou, Retry-After, absence de deuxième POST, lecture IPC sans données privées, sérialisation des erreurs, boutons de plusieurs profils, expiration et absence de relance automatique. Les tests simulent le client : aucun essai interactif Windows/LoL ni appel Riot authentifié n'est effectué.

Version nouvelle 5.19.1, jamais remplacement d'un installateur existant ; version d'interface toujours fournie par Electron app.getVersion(). Contrôles Windows, extraction du véritable NSIS et inspection indépendante de l'asset publié requis. Preuve commit → build → installateur, empreinte, contenu embarqué et tests extraits consignés dans la PR après publication.
