# MidPulse 5.24.0 — Comparer les rangs sur les mêmes rôles

Équipes OUAT → adversaire → sommaire PRÉPARATION → Rangs comparés. Le nouveau panneau apparaît après les effectifs, avant le suivi Riot.

Les moyennes individuelles peuvent couvrir des rôles différents ; elles restent inchangées et indépendantes, comme le tableau du groupe. Le nouveau panneau calcule deux moyennes descriptives sur exactement les mêmes rôles : rang complet récent exploitable des deux côtés, un seul joueur déclaré ou choisi localement par rôle. Il affiche le nombre de rôles communs sur cinq, la liste de ces rôles, les deux moyennes, les cinq lignes avec joueurs, rangs disponibles/dates et raisons d’exclusion. Un rôle indisponible d’un côté est exclu des deux moyennes, jamais remplacé par zéro.

Rangs périmés/futurs, erreurs, résultats partiels, non-classés, comptes absents ou partagés entre rôles, sélection ambiguë/retirée sont exclus selon les contrôles existants. Contrôles additionnels pour ce périmètre commun : compte du rang absent des comptes actuels du joueur, et compte présent dans les deux équipes, même à des rôles différents. Aucune moyenne si aucun rôle commun ; pas d’extrapolation à cinq joueurs.

La conversion reste celle des rangs officiels déjà utilisée : 100 points/division, 400/palier + LP ; Master/Grandmaster/Challenger = base Master + LP. Pas de MMR réel, score de menace ou pronostic. Les choix locaux ne confirment pas les titulaires LEA. Aucun nouvel appel Riot. L’export de préparation reprend le même périmètre commun avec les exclusions ; les détails individuels gardent les Riot IDs et horodatages publics existants.

Douze nouvelles régressions : cinq rôles, intersections différentes malgré deux couvertures individuelles identiques, absence de rôle commun, dates/erreurs/partiels, compositions locales/ambiguïtés, comptes partagés intra/inter-équipes, ancien compte du rang absent, absence de mutation et d’adversaire, expiration/Master+, véritable renderer en VM et export sans champs privés. Le test du sommaire et le contrôle du paquet sont actualisés pour le nouvel accès Rangs comparés, sans retirer le contrôle effectifs-en-premier.

Version unique 5.24.0, interface depuis Electron app.getVersion(). Livraison : régressions Windows, téléchargement public, SHA-256, extraction NSIS/app.asar, version/fichiers et tests sur code extrait. Preuves finales dans la PR. Aucun test interactif Windows/LoL ni appel Riot authentifié ; les tests UI sont simulés et ne valident pas le parcours sur la machine du propriétaire.

Veille du 19 octobre 2026 : https://developer.riotgames.com/docs/lol (rangs officiels, pas d’estimation MMR alternative), https://developer.riotgames.com/docs/portal (quotas conservés), https://dpm.lol/changelog (outils de scouting). Les effectifs sont renouvelés depuis LEA au build, sans joueur/Riot ID/rang inventé.
